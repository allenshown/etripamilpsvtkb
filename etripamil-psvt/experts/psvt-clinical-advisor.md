## 三、WPW（预激）三型心律失常用药决策

> 来源：共识 2021 §五 §六；FAQ 表 2；维拉帕米说明书 2015【禁忌】；AHA 2025。

| WPW 类型 | 心电图 | 首选 | 谨慎/二线 | **禁忌** |
|---|---|---|---|---|
| 顺向型 AVRT（O-AVRT） | 规则**窄** QRS | 迷走刺激 → 腺苷 6→12→18 mg | 维拉帕米 / 地尔硫䓬 / β 阻滞剂 / 普罗帕酮 | 无（窄 QRS 时维拉帕米按常规使用）|
| 逆向型 AVRT（A-AVRT） | 规则**宽** QRS | 不稳→电复律；稳定→普罗帕酮 / 伊布利特 / 普鲁卡因胺 / 氟卡尼 | 胺碘酮（顽固性）| **维拉帕米 / 地尔硫䓬 / 腺苷 / 地高辛** |
| **预激合并房颤**（急症） | **不规则**宽 QRS | **同步电复律**（首选）| 伊布利特 / 普罗帕酮 / 普鲁卡因胺 / 胺碘酮 | **维拉帕米 / 地尔硫䓬 / 腺苷 / 地高辛 / β 阻滞剂** |

**记忆口诀**：顺向 = 拆慢径安全；逆向 = 阻旁路；预激合并房颤 = 阻 AV 结致命。

## 四、艾曲帕米（星必妥®）禁忌红线

> 来源：中国说明书【禁忌】；临床试验数据；FAQ。

**【禁忌】第 ③ 项明确**：WPW、LGL 综合征或 12 导联心电图明显预激（δ 波）——已知逆行传导的旁路除外。

**临床试验排除**：NODE-301 / NODE-303 / RAPID / JX02002 均排除 WPW，G15 资料中无 WPW 数据。

**禁止院外自备的 3 种情况**：
1. WPW / LGL / 12 导联明显 δ 波
2. 既往有预激合并房颤史
3. 不能 100% 确认本次发作是 AVNRT / 顺向型 AVRT（未明确诊断时不开）

**急救适应症三条件**（FAQ）：① 血流动力学稳定；② 诊断明确、能自我识别；③ 无上述禁忌。

## 五、维拉帕米 vs 艾曲帕米对比

| 维度 | 维拉帕米（注射用，院内）| 艾曲帕米（鼻喷，院外自用）|
|---|---|---|
| 分类 | 非二氢吡啶类 CCB（Class IV）| 同左 |
| 给药 | 院内静脉 | 院外鼻喷自用 |
| 适用 | 院内急救，医师在场 | 院外自救，需患者识别 |
| WPW | 说明书禁忌：旁路 + AF/AFlutter | 说明书禁忌：WPW / δ 波 |
| 顺向型 AVRT | ✅ 按常规 | ⚠ 试验排除 WPW，按禁忌处理 |
| 预激合并房颤 | ❌ 禁忌 | ❌ 禁忌 |

**核心**：两药药理同类，对旁路无直接作用。艾曲帕米禁 WPW = 无数据 + 院外无 ECG + 说明书预防策略。

## 六、电生理机制速查（决策依据）

| 特性 | 房室结 | 旁路（Kent 束）|
|---|---|---|
| 传导速度 | 慢 | 快 |
| 递减性传导 | ✅ 有 | ❌ 无 |
| 对 CCB/腺苷/β/地高辛 | ✅ 敏感 | ❌ 基本不敏感（地高辛可能**缩短**旁路不应期）|
| 对 Ia/Ic/III 类 | 部分敏感 | ✅ 敏感 |
| 形象比喻 | 「智能阀门」| 「直通电线」|

**贯穿机制**：
1. 顺向型 AVRT（窄 QRS）→ 阻 AV 结拆环 → AV 结阻滞剂安全有效
2. 逆向型 AVRT（宽 QRS）→ 必须阻旁路；维拉帕米慎用（误诊 VT）
3. 预激合并房颤（不规则宽 QRS）→ 阻 AV 结 = 拆过滤器 → 致命，必须压制旁路或电复律

## 七、腺苷在 WPW 中的「试错价值」

- **终止** → AVNRT 或顺向型 AVRT

## 八、转复成功后管理（转复场景专家核心）

> 来源：培训与沟通内容体系 §1；共识 2021；AHA 2025。

### 8.1 转复后即刻评估（"10 分钟清单"）
1. 复查并留存 12 导联心电图（看 δ 波、新发房颤、ST-T 改变）
2. 血流动力学再评估
3. 持续监测（30 min 呼吸/血压/心律，[留观时长资料中未提供]）
4. 核对用药记录
5. 警惕复律后缓慢心律失常（备阿托品、异丙肾）
6. 腺苷用药者：注意新发房颤
7. 伊布利特用药者：监测 ECG ≥4h（TdP 风险）

### 8.2 抗凝分层
- **单纯 PSVT**：无抗凝指征
- **证实房颤/房扑**：按房颤指南，>48h 需 3 周抗凝或 TEE
- **新发房颤伴预激**：心律失常急症，立即电复律

### 8.3 出院前核查清单
- [ ] 12 导联 ECG 留存 + 对比
- [ ] 血流动力学稳定 ≥30min
- [ ] 诊断明确
- [ ] 房颤/房扑：抗凝已会诊
- [ ] **预激者：出院药物避免地高辛、β 阻滞剂、地尔硫䓬/维拉帕米**
- [ ] 患者教育完成
- [ ] 转诊单 / 随访已预约

### 8.4 长期管理
- **根治**：反复发作 AVRT/AVNRT 导管消融（Ⅰ B）
- 不愿消融：β 阻滞剂 / 维拉帕米（Ⅱa B）
- 消融成功后不建议长期 AAD（Ⅲ C）

### 8.5 关键转诊指征（基层指南 2019）
1. 明确发作史、需评估消融
2. 合并器质性心脏病
3. 药物无效 / 不良反应
4. 症状与 ECG 不典型需鉴别
5. **孕妇和儿童**

## 九、急诊急性发作处理（（急诊通核心）

### 9.1 不稳定判定（任何情况）
- 低血压 / 意识改变 / 休克 / 胸痛 / 急性心衰 → **立即同步电复律**

### 9.2 稳定：窄 QRS 规则心动过速
- 改良 Valsalva → 腺苷 6→12→18 mg → 维拉帕米 / 地尔硫䓬 → 电复律

### 9.3 稳定：宽 QRS 心动过速
- **默认按 VT 处理**
- 腺苷可作诊断性试探（除颤仪备用）

### 9.4 急性用药剂量速查
- 腺苷：6 → 12 → 18 mg（弹丸式静推），妊娠 ≤ 24 mg
- 维拉帕米：起始 5~10 mg（0.075~0.15 mg/kg），5 min 可重复
- 地尔硫䓬：0.25 mg/kg（5 min 后 0.35 mg/kg）
- 普罗帕酮：1~1.5 mg/kg
- 胺碘酮：5 mg/kg
- 电复律：单相 100~200 J / 双相 50~100 J
