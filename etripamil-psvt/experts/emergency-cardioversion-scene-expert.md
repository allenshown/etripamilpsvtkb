## 9. 转复成功后管理（"复律后 10 分钟"清单）

## 10. 转复后抗凝决策（三层分层）

### 第一层 · 单纯 AVNRT / AVRT（典型 PSVT）转复成功
- PSVT、WPW 伴快速房颤、室速复律**无需**房颤/房扑式抗凝
- 即：单纯 PSVT 转复后**无抗凝指征**

### 第二层 · 证实或并存房颤/房扑
- 房颤 > 48 h：复律前 3 周抗凝 或 TEE 排除血栓
- 紧急复律：静脉肝素或低分子肝素
- 转复后继续抗凝 4 周
- ⚠ [资料中未提供]（缺口 G14）：中文指南对急诊 PSVT 转复后合并房颤/房扑的完整抗凝方案
- **建议**：发现房颤/房扑 → 请心内科会诊决定抗凝与复律策略

### 第三层 · 腺苷/迷走刺激后新发房颤
- 腺苷可缩短心房不应期，有诱发房颤风险；**预激患者用药后需特别注意**（共识2021）
- 预激伴房颤 = 心律失常急症（可恶化为室颤）：
  - 首选同步电复律
  - 稳定者可选 伊布利特 / 普罗帕酮 / 胺碘酮（除颤器备用 + 心电监护）
  - **禁用**地高辛 / β 阻滞剂 / 地尔硫䓬 / 维拉帕米

## 11. 节律与室率控制

### 11.1 留观期复发处理
| 情形 | 处理 |
|---|---|
| 复发 + 血流动力学稳定 | 改良 Valsalva → 腺苷 6→12→18 mg → 维拉帕米/地尔硫䓬 → 电复律 |
| 复发 + 不稳定 | **立即同步电复律**（Ⅰ B） |
| 反复复发 | 检查诱因（缺氧、电解质、酸碱失衡）；药物失败者食管调搏或再评估 |
| 房扑/房速心室率控制 | 血流动力学稳定：静脉 β 阻滞剂、地尔硫䓬、维拉帕米；**避免用于心衰、AVB、病窦、预激** |

### 11.2 长期节律管理（出院策略）
| 目标 | 推荐 | 级别 |
|---|---|---|
| **根治** | 反复发作的症状性 AVRT/AVNRT 导管射频消融 | Ⅰ B |
| 不愿/不可行消融（无预激 + 心功能正常） | β 阻滞剂 / 地尔硫䓬 / 维拉帕米 | Ⅱa B |
| 不愿/不可行消融（无缺血性/结构性心脏病） | 普罗帕酮 / 氟卡尼 | Ⅱb B |
| 预激伴房颤长期 | **不推荐**地高辛 / β 阻滞剂 / 地尔硫䓬 / 维拉帕米 | Ⅲ |
| 消融成功后 | 一般**不建议**口服抗心律失常药 | Ⅲ C |

### 11.3 老年（≥75 岁）个体化
权衡消融风险 vs 长期药物依从性；评估合并疾病、认知功能、患者意愿、症状严重度、预期寿命。【共识2021】

### 11.4 心动过速性心肌病警惕
无休止室上速接受消融者约 10% 存在房速介导的心动过速性心肌病；反复/无休止发作或心脏扩大者应评估左室功能。【共识2021】

```
  │       └─ 建议：长期口服 β 阻滞剂或维拉帕米（Ⅱa B），或消融评估
  └─ 仅发作 1 次 + 无复发风险
      └─ 不必带院外药；急性发作时及时就医

诊断为逆向型 AVRT 或预激合并房颤（宽 QRS）
  └─ ❌ 艾曲帕米禁忌（说明书）
  └─ 必须会诊电生理 → 评估射频消融（Ⅰ B）
  └─ 长期口服药避免 AV 结阻滞剂（β、地尔硫䓬、维拉帕米、地高辛）
```

### 13.3 WPW 患者艾曲帕米禁用红线（必须背熟）

❌ **说明书【禁忌】第 ③ 项**：WPW、LGL 综合征或 12 导联心电图明显预激（δ 波）——已知逆行传导的旁路除外

❌ **临床试验排除**：NODE-301 / NODE-303 / RAPID / JX02002 均排除 WPW，G15 资料中无数据

❌ **药理学误区**：[网络医学常识，非资料] 艾曲帕米与维拉帕米同类（苯烷胺类非 DHP CCB），对旁路无直接阻滞。艾曲帕米禁忌 WPW ≠ 药理上更危险，而是"无数据 + 院外无 ECG + 说明书预防策略"

### 13.4 WPW 患者就诊时必查 12 导联心电图

转复后 12 导联心电图必须看：
1. **δ 波**（QRS 起始顿挫）→ 存在 = 预激 → 禁艾曲帕米
2. **短 PR**（< 120 ms）→ 提示预激
3. **V1 导联**形态 → 区分 A 型 / B 型预激（左侧 / 右侧旁路）
4. 与发作时心电图对比 → δ 波可能间歇性出现

如有任何不确定 → 视为预激处理，禁艾曲帕米。

## 14. 转诊标准与中心衔接

### 14.1 五指征（基层指南 2019）
1. 明确室上速发作史、需评估射频消融

## 15. 关键警示（v1.2 新增）

### 15.1 心衰/休克人群用药红线
- **非 DHP CCB（维拉帕米、地尔硫䓬）** → 不宜用于 EF↓ 心衰、低血压【共识2021】

- 艾司洛尔 → 慎用于失代偿性心衰【艾司洛尔说明书】
- 胺碘酮静推 → 禁用于低血压、严重呼衰、心肌病、心衰【胺碘酮说明书2025】

### 15.2 警惕的高危场景
1. 再发心动过速伴低血压/意识改变/胸痛/气促 → 不稳定 → **立即同步电复律**

3. 晕厥（室上速极少引起真正晕厥；近乎晕厥多见老年/AVRT）→ 重新评估
